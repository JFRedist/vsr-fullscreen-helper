# Privacy Policy

**VSR Fullscreen Helper** does not collect, store, transmit or share any personal or usage data.

- It makes no network requests and loads no remote code.
- It has no analytics or telemetry, and does not use cookies, `chrome.storage`, or any other storage.
- Its content script runs on all pages so a hotkey can find the playing `<video>`, but it only reads the page's DOM and styles in memory, when you press a hotkey. Diagnostic output is printed to your own browser's developer console and goes nowhere else.

If this policy changes, the change will be published in this repository.

Contact: open an issue in this repository.

# 隐私政策

**VSR Fullscreen Helper** 不收集、存储、传输或分享任何个人数据或使用数据。

- 不发送网络请求，不加载远程代码。
- 无统计或遥测，不使用 cookie、`chrome.storage` 或其他任何存储。
- content script 在所有页面运行，是为了让快捷键能找到正在播放的 `<video>`；它只在你按下快捷键时在内存中读取页面的 DOM 和样式。诊断信息只打印到你自己浏览器的开发者控制台。

政策如有变更，将在本仓库中发布。

联系方式：在本仓库提交 issue。
